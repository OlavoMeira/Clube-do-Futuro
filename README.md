# 🚀 Clube do Futuro — Programação Web

Bem-vindo ao repositório central do **Clube do Futuro**! Este é o espaço onde reunimos todos os projetos, desafios, códigos e atividades práticas do nosso curso de programação web, desenvolvido especialmente para jovens mentes brilhantes de 12 anos ou mais.

Aqui, transformamos ideias em linhas de código e páginas web reais. 🌐✨

---

## 🎯 Objetivo do Curso

O Clube do Futuro foi criado para introduzir os fundamentos do desenvolvimento web de forma prática, divertida e direto ao ponto. Ao longo da nossa jornada, os alunos aprendem a dominar as ferramentas que constroem a internet moderna, desenvolvendo a lógica de programação, a criatividade e a resolução de problemas.

---

## 🛠️ O que estamos aprendendo?

Nossa stack de estudos é focada nas tecnologias fundamentais da web:

* **HTML5:** A estrutura e a base de qualquer página na internet.
* **CSS3:** Estilização, cores, layouts modernos e animações para dar vida aos projetos.
* **Lógica de Programação:** Entendendo como computadores pensam e resolvem desafios.

---

## 📂 Organização do Repositório

O repositório está dividido por pastas para facilitar a navegação dos alunos:

* `/atividades`: Pequenos desafios de código e exercícios de fixação feitos em sala.
* `/projetos`: Os projetos principais e páginas completas desenvolvidas durante o curso.
* `/materiais-de-apoio`: Guias rápidos, cheatsheets (folhas de cola) e links úteis.
